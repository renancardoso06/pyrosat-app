# VigIA

Monitoramento de queimadas em tempo real via satélite, com previsão de risco por bioma usando IA.

## Tecnologias

- flutter_map + OpenStreetMap

## Como rodar
```bash
flutter pub get
flutter run -d chrome        # web
flutter run -d emulator-5554 # android
```
